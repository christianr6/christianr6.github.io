### 1.4 Decision gates: 65 vs 66 vs CFP waiver

```
IF employer = BD or dual registrant (commissions + fees)      -> THEN SIE -> S7 -> S66. Never S65.
IF employer = RIA-only AND advisory role starts before CFP marks are held
                                                              -> THEN S65 now. Do NOT wait for waiver.
IF no IAR function needed until after CFP certification        -> THEN skip S65; request state waiver (CFP in good standing).
IF CFP marks held AND later join BD needing agent registration -> THEN SIE + S7 + S63 only (CFP waives the 65 component; S66 unnecessary).
IF S65/S66 passed AND unregistered > 2 yr (no EVEP)            -> THEN exam lapses -> retake or use CFP waiver.
IF SIE passed AND no representative exam within 4 yr           -> THEN SIE expires -> retake.
IF solicitor/adviser in multiple states                        -> THEN waiver is state-by-state; confirm each Administrator (CA: 10 CCR §260.236).
```

| Question | Rule |
|---|---|
| What does the CFP waiver cover? | The IAR competency exam (Series 65) only. Same waiver class: CFP, CFA, ChFC, PFS, CIC. Requires the **credential in good standing**, not a passed CFP exam |
| Why the waiver arrives late | CFP certification = education + exam + **6,000 hr** experience (4,000 apprenticeship) + bachelor's + ethics. Passing the exam ≠ holding the marks -> multi-year gap with no IAR authority |
| Why CFP does not waive S66 | (1) S66 = S63 (agent/BD state law) + S65 (IAR) combined; no designation covers the S63 agent component. (2) S66 omits product/analysis depth because S7 is its corequisite; the waiver model rule names the IAR exam, not the combined exam. (3) Waiver authority is the state Administrator's over IAR qualification; agent qualification runs through FINRA exams + S63, which no credential waives |
| Does CFP waive SIE / S7? | No. FINRA grants no designation-based waiver |
| Does EA or CA L&H waive anything? | No securities waiver. CFP holders get no CDI exam waiver. EA = unlimited IRS practice rights; no CFP education waiver (CPA/attorney/CFA/ChFC/CLU/PhD holders get CFP coursework challenge status; EA does not) |

### 2.1 Who is the person? (definition gate)

| Term | Definition | Is a firm? | Key exclusions | Registers with |
|---|---|---|---|---|
| IA | Advice on **securities** + **in the business** + **compensation** (SEC Rel. IA-1092 three-prong) | Yes (sole prop counts) | `LATE` (lawyer, accountant, teacher, engineer) if advice solely incidental · BD/agents w/ no special compensation · bona fide publishers (general, impersonal) · banks/trust cos · US gov securities-only advisers · federal covered advisers (state definition) | SEC **or** state, never both |
| IAR | Individual who, for an IA: gives advice, manages accounts, determines recommendations, solicits/sells advisory services, or supervises those who do | No | Clerical/ministerial staff | **State only** (never SEC) |

### 2.3 State de minimis / registration gates (USA + NSMIA)

```
IA:    IF no place of business in state AND (clients only institutions/IAs/BDs OR ≤ 5 non-institutional clients in 12 mo)
       -> THEN no state registration (National De Minimis Standard).
       IF place of business in state -> THEN register (state adviser) or notice-file (federal covered), any client count.
IAR:   IF firm is federal covered -> THEN state may register IAR only where IAR has a place of business.
       IF firm is state-registered -> THEN IAR follows firm; de minimis mirrors IA.
BD:    IF no place of business AND clients only issuers/BDs/institutions -> THEN not a BD in that state.
       IF existing customer is non-resident temporarily in state (≤ 30 days, snowbird) -> THEN no registration.
       IF any retail resident client -> THEN register. NO retail de minimis for BDs.
AGENT: IF agent's BD must register in state -> THEN agent registers. No de minimis.
       IF BD withdraws/terminates -> THEN agent registration not effective.
FEDERAL COVERED IA: state may demand notice filing (ADV copy + fee + consent to service), may enforce anti-fraud; may NOT impose
       net worth, bond, or books-and-records rules beyond home state / SEC.
```

### 2.4 Standard-of-care gate

| Dimension | CFP Board (Code & Standards) | SEC IA fiduciary (Advisers Act §206) | SEC Reg BI | USA / NASAA unethical practices |
|---|---|---|---|---|
| Applies to | CFP professional giving **Financial Advice** to a **Client** | IA + supervised persons, entire relationship | BD + associated persons, **recommendation to retail customer** | State-registered IA/IAR/BD/agent |

| Document | Written info at/before engagement; written scope if planning | Form ADV 2A/2B + Form CRS | Form CRS | State brochure rule |

```
IF CFP professional's other standard is lower (Reg BI, insurance suitability) -> THEN higher (CFP fiduciary) controls.

## 3. PRE-CALCULATION INVARIANT LOCK (5-POINT CHECK)

`RULE: no keystroke and no arithmetic until all five gates return PASS. One FAIL -> stop, re-read the stem.`

### GATE 1 — Periodicity alignment

| Check | Invariant | IF -> THEN |
|---|---|---|
| `P/Y` vs `C/Y` | `N`, `I/Y`, `PMT` share one period | `IF payments monthly -> P/Y=12, N=years×12 (n 2ND [xP/Y]). IF payment freq != compounding freq -> set C/Y separately.` |
| EAR vs APR | `EAR = (1 + APR/m)^m − 1` | `IF comparing products with different m -> convert all to EAR. IF stem gives EAR and needs monthly rate -> (1+EAR)^(1/12) − 1, not EAR/12.` |
| Bonds | US corporate/muni/Treasury coupons **semiannual** | `N = years×2 · PMT = coupon/2 · I/Y = YTM/2 · reported YTM = periodic × 2 (BEY).` Zero-coupon: still semiannual discounting. |
| Inflation-adjusted rate | `r_real = (1+nominal)/(1+inflation) − 1` | `IF growing payments -> real rate. IF level payments -> nominal. Never nominal − inflation.` |
| Yield annualization | `IRR` from CF worksheet = per-period | `IF CFs monthly -> ×12 (nominal) or compound (effective).` |

| **§83(b)** | Restricted stock: elect within **30 days** of grant; ordinary on grant FMV; no refund if forfeited. RSUs: not eligible |

| **§1035** | Allowed: life->life, life->annuity, life->LTC, annuity->annuity, annuity->LTC, endowment->annuity. **Never annuity->life**. Same insured/owner; basis carries; loan extinguished = boot; MEC stays MEC |

| **Gift (§1015)** | Carryover basis + tacked holding period. `IF FMV@gift < donor basis -> dual basis: gain basis = donor's; loss basis = FMV@gift; sale between = no gain/loss.` Add gift tax × (appreciation / taxable gift) |

| **Loss ordering** | Basis -> at-risk (§465) -> passive (§469) -> excess business loss (§461(l)) |
| **Other locks** | Wash sale: ±30 days (61-day window), loss added to replacement basis, IRA purchase triggers permanently. ### GATE 5 — Output sanity (unit / magnitude / question asked)

```

| 1 | S7 / Options | Long straddle: buy 50 call @3 + 50 put @2; "breakeven?" | Uses one premium or gives one BE | **Two BEs = strike ± combined premium** -> 55 and 45. Max loss = total premium ($500). Short straddle: same BEs, unlimited loss |
